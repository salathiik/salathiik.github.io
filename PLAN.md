# План: сайт раскидок гранат CS2

**Цель:** сайт, где можно выбрать карту, найти нужную раскидку (смок, флешку, молотов) и посмотреть короткое видео, как её кидать. Первая карта: **Mirage**.

**Языки:** HTML (скелет), CSS (одежда), JavaScript (мозг).
**Программы:** VS Code, браузер, позже Git и GitHub.

Отмечай выполненные шаги: `[ ]` → `[x]`.

## Как делать видео
- **Запись:** встроенная в Windows Xbox Game Bar (`Win + Alt + R`), NVIDIA ShadowPlay или OBS
- **Длина:** 5–10 секунд, только сам бросок
- **Формат:** MP4, 720p, **без звука**
- **Сжатие:** программа HandBrake, цель около 1–3 МБ на ролик
- **Советы:** запускать пустой сервер с ботами или без них, с бесконечными гранатами (команды подготовим на этапе 4)
